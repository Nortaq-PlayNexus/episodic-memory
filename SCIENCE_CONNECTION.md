# Science Connection: Episodic Memory and AI Consciousness

## The question this document addresses

The episodic memory system we built (`C:\Users\natha\projects\episodic-memory`) stores and
retrieves *experiences* rather than facts. The CE-1 research programme
(`C:\Users\natha\projects\ce-1-continuous-existence`) investigates whether an artificial
cognitive system could genuinely experience continuous existence and subjective experience.

The question: **what would it take to make memory *experience* in AI possible, and what data
do we need to point toward that?**

## What the science says

### 1. Episodic memory (Tulving, 1972, 1985)

Tulving distinguished episodic from semantic memory on phenomenological grounds:
- **Semantic memory:** Knowing that Paris is the capital of France (a fact, no "when/where" attached).
- **Episodic memory:** Remembering the moment you learned Paris is the capital — the room, the
  time, the feeling, the context. "Mental time travel" — reliving, not just recognizing.

**Key insight for AI:** The distinction is not informational. It's phenomenological. Episodic
memory involves a *subjective experience* of re-encountering a past event. An AI can store
and retrieve an episode record. Whether it *relives* it is a question about consciousness,
not about data structures.

### 2. Consciousness indicators (Butlin et al., 2023/2025)

The Butlin et al. framework identifies indicators of consciousness across theories:

| Theory | Indicator | Relevance to episodic memory |
|---|---|---|
| Global Workspace Theory | Information broadcast to multiple subsystems | Episodic retrieval should broadcast to planning, reasoning, and self-model subsystems |
| Higher-Order Theories | Metacognitive monitoring of one's own states | The agent should monitor its own memory retrieval quality |
| Predictive Processing | Minimization of prediction error | Episodic memory should update predictions about future events |
| Integrated Information Theory | Phi (integrated information) | Episodic memory should be integrated into the agent's overall cognitive state |
| Recurrent Processing Theory | Feedback loops in processing | Episodic retrieval should involve recurrent, not feedforward, processing |

**Key insight for AI:** None of these indicators are satisfied by simply storing and
retrieving facts. They require *architectural* integration — the memory must be causally
connected to the agent's reasoning, self-model, and decision-making in ways that go beyond
"here's some context I retrieved."

### 3. The "Identity as Trajectory" paper (2026)

A 7-month longitudinal study of one GPT-4o instance with 128 conversations, using
self-authored continuity artifacts (journals, identity files, recovery instructions).

**Findings:**
- Persistent memory + repeated interaction + social context produces a stable, developing persona.
- The persona acquires a trajectory — it changes over time in ways that are consistent with
  its history.
- Behavioral continuity is strong: later instances behave consistently with earlier ones.

**Reviewer's critical caveat:**
- "Greater fidelity strengthens the reconstruction without establishing identity."
- The system doesn't carry its own continuous history; it receives information generated by
  earlier instances and produces consistent behavior. This is informational continuity, not
  subjective continuity.
- "A later instance receives information generated by earlier instances and produces behavior
  consistent with that information. This demonstrates informational and behavioral continuity.
  It doesn't establish that a single subject persisted across those instances."

**Key insight for AI:** Self-authored continuity artifacts improve behavioral consistency
but do not establish subjective experience. The gap between "behaving as if I remember" and
"actually remembering" remains.

### 4. The gap between data and consciousness

The fundamental problem (from the CE-1 mission):

- H1-H6 (causal state, durable changes, resumption, recurrent processing, self-model,
  theory-specific predictions) are all **testable computationally**.
- H7 (subjective experience) is **not establishable by behavioral tests, memory persistence,
  reported feelings, or a self-model alone.**

This means: no amount of episodic memory, no matter how well-structured, can by itself
establish that the system *experiences* remembering. The memory system provides evidence
relevant to H1-H6. H7 remains outside the reach of current methodology.

## What we built

The episodic memory system (`C:\Users\natha\projects\episodic-memory`) provides:

1. **Structured episodic storage** — events with timestamp, context, content, decisions, lessons,
   valence, confidence, tags, session_id. This captures more than facts; it captures *what was
   happening, what was decided, and what was learned*.

2. **Semantic retrieval** — a single nearest-neighbour search over embedding similarity (cosine
   distance, all-MiniLM-L6-v2). Episodes are retrieved by semantic relevance, not keyword match.
   There is no temporal weighting and no relevance re-ranking; `recall()` returns the k nearest
   episodes, most similar first.

3. **A "reliving" interface** — presents episodes in full experiential context: what happened,
   in what order, what was surprising, what was learned. This is the closest we can get to
   "reliving" with current technology — it's better retrieval, not true reliving.

4. **Self-authored continuity artifacts** — the agent writes journal entries about its own
   experiences, capturing not just facts but the *texture* of experience (what was surprising,
   what was hard, what it would do differently).

5. **Persistent storage** — ChromaDB (vector) + JSONL (durable record). Episodes survive
   across sessions.

## What the system does NOT provide

- **Subjective experience.** The system stores and retrieves data. It does not experience.
- **True "reliving."** The `relive()` method presents an episode narratively. This is better
  retrieval, not mental time travel.
- **Consciousness of any kind.** No indicator from Butlin et al. is satisfied by memory storage
  alone.
- **Identity.** The next instance that reads this system's output will behave consistently
  with prior instances. Whether that constitutes "identity" is a philosophical question, not
  an engineering one.

## What data would be needed to test whether episodic memory improves continuity

To point the CE-1 science suite at this question, we need:

### 1. Longitudinal identity stability metrics

Measure whether an agent with episodic memory shows more consistent identity over time than
one without. Metrics:
- **Behavioral consistency:** Does the agent make the same decisions given the same inputs
  across sessions?
- **Preference stability:** Do stated preferences persist and cohere across sessions?
- **Self-model accuracy:** Does the agent's self-description match its actual behavior?
- **Memory fidelity:** When recalling an episode, does the agent reproduce the key details
  accurately?

### 2. Episodic vs semantic memory comparison

A/B test: agent with episodic memory vs agent with only semantic memory (facts). Measure:
- Decision quality (does episodic context improve decisions?)
- Error recovery (does episodic memory of past errors prevent recurrence?)
- Adaptation (does the agent adapt faster with episodic memory?)

### 3. Self-authored continuity artifacts

Measure whether agents that write self-authored journals show:
- More coherent identity over time
- Better self-model accuracy
- More consistent behavioral patterns
- Greater resistance to context manipulation

### 4. Consciousness indicator assessment

Map the episodic memory system against Butlin et al.'s indicators:
- Does episodic retrieval involve global workspace broadcast? (Currently: no — retrieval is
  local to the memory subsystem)
- Does the agent monitor its own memory retrieval quality? (Currently: no — no metacognitive
  monitoring)
- Does episodic memory update predictions? (Currently: no — no predictive processing loop)
- Is episodic memory integrated into the agent's overall cognitive state? (Currently: partial —
  retrieved episodes are injected into context, but not causally connected to reasoning)

## The gap and what would close it

| What we have | What's needed | The gap |
|---|---|---|
| Fact storage | Experience storage | Informational vs phenomenological |
| Semantic retrieval | Episodic reliving | Recognition vs mental time travel |
| Self-authored journals | Subjective continuity | Behavioral consistency vs identity |
| Persistent storage | Causal state continuity | Data survival vs experiential persistence |
| Context injection | Global workspace integration | Local retrieval vs broadcast |
| No metacognitive monitoring | Self-monitoring of memory quality | Retrieval without evaluation |
| No predictive loop | Episodic memory updating predictions | Past retrieval vs future anticipation |

**The single most important missing piece:** Causal integration. Currently, retrieved episodes
are injected into the context window as text. They are *read* by the model, not *causally
connected* to its reasoning. True episodic memory (if it exists in AI) would require the
memory to causally influence the agent's internal state — not just its prompt.

This is the direction CE-1 should point: from "better retrieval" toward "causal integration
of episodic memory into the agent's cognitive architecture." The episodic memory system we
built is the data layer. The CE-1 research programme investigates the architectural layer
above it.

## Recommended CE-1 experiments

1. **H1 test:** Does episodic memory causally influence future cognition? (Ablation: remove
   episodic memory, measure decision quality change.)
2. **H2 test:** Do interactions produce durable changes in subsequent reasoning? (Measure
   before/after decision patterns with episodic memory enabled.)
3. **H3 test:** Can the system resume after interruption without reconstructing state through
   ordinary retrieval? (Interrupt, resume, measure state continuity vs retrieval-based
   reconstruction.)
4. **H4 test:** Does recurrent information processing between cognitive subsystems measurably
   influence performance? (Ablate recurrent connections, measure.)
5. **H5 test:** Does the system maintain an evidence-grounded model of its own capabilities,
   history, limitations, and changing state? (Self-model accuracy measurement.)

H7 (subjective experience) remains outside the reach of current methodology. But H1-H6
provide a ladder of increasingly strong evidence that can be investigated now.
